Architecture Radar is a reference implementation for running a scheduled AI research agent that opens evidence-backed pull requests instead of sending disposable digests.

## Highlights

- Scheduled GitHub Actions workflow for recurring research.
- Codex research step separated from GitHub publishing credentials.
- Pull request publication with an explicit artifact allowlist.
- Evidence taxonomy for source-verified facts, test-verified behavior, maintainer claims, interpretation, and hypotheses.
- Deterministic validation for required radar structure and evidence-label consistency.
- Candidate ledgers that record rejected and deferred repositories, not only selected ones.
- Rerun and cadence guards to avoid spending tokens when inputs have not changed.
- Local helpers for reviewing generated radar PRs.
- Example scope for opportunity and demand research.
- MIT license and GitHub community health files.

## Known Limits

- Generated research still requires human review.
- The evidence validator catches common path/label inflation, not every possible weak claim.
- Public users must configure their own OpenAI key, GitHub Actions permissions, branch protection, and research scope.
- Costs depend on model choice and the amount of source inspected per run.
