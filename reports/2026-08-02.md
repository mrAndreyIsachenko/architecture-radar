## Executive Summary

This first run adds one cross-repository pattern, [Evidence-Carrying Execution Envelopes](../patterns/evidence-carrying-execution-envelopes.md), grounded in three independent implementations:

- LangGraph shows how checkpoint envelopes can preserve resumable agent execution state, parent checkpoint links, pending writes, task streams, and human interrupt/error recovery.
- OpenLineage shows how versioned event/facet envelopes preserve producer identity, schema identity, run/job/dataset identity, parent run causality, and column lineage across runtimes.
- Graphiti shows how episode envelopes can anchor LLM-extracted temporal facts back to source records while preserving `valid_at`, `invalid_at`, and `expired_at`.

The reusable recommendation is not to adopt any whole project as-is. The recommended mechanism is to design an internal evidence envelope that can be emitted by agents, workflow engines, metadata systems, and knowledge-graph ingestion pipelines, then deterministically projected into an execution graph.
