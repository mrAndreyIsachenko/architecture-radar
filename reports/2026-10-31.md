## Detailed Reviews

### juanfont/headscale

This repository informs `privacy-networking-vpn` through reconnect recovery plus stale-timer suppression. The current head keeps the reconnect and policy model intact, but it now closes a stale ephemeral-GC hole by deferring timer cancellation until after `Connect`, rejecting timers for nodes that are no longer ephemeral, and dropping queued deletions when the node has a live session. See [juanfont/headscale](../repositories/juanfont-headscale.md).

The remaining gap is live reconnect-storm and HA churn validation. The source and tests pin the intended invariants, but they still need multi-node operational proof.

### docling-project/docling

This repository informs `document-ai-ocr` through spreadsheet provenance and image extraction. The current head keeps the PDF pipeline intact and adds XLSX rich-value image handling: image-bearing cells become picture-backed table cells, fallback error cells can still be recovered, and singleton image sheets can be promoted without losing labels or table provenance. See [docling-project/docling](../repositories/docling-project-docling.md).

The remaining gap is runtime validation on a mixed workbook corpus. The source and tests verify the new path, but the XLSX image-cell behavior still needs an end-to-end workload pass.

### PX4/PX4-Autopilot

This repository informs `drones-robotics-autonomy` through mission-planning and recoverable command transactions. The refreshed head keeps the autonomy safety model intact while expanding the MAVLink parameter and mission paths: rejected parameter writes still return the current value, buffer saturation stays distinct from missing parameters, and recoverable mission requests preserve the expected cursor. See [PX4/PX4-Autopilot](../repositories/PX4-PX4-Autopilot.md).

The remaining gap is live SITL validation. Source and tests are strong, but the refreshed protocol paths still need a simulator run.
