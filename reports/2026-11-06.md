## Detailed Reviews

### tunnexio/tunnex

This repository informs `privacy-networking-vpn` through a capability-scoped origin projection and recovery boundary. The verified flow is: browser-supplied request -> origin-policy normalization and validation -> per-request DNS resolution and TLS pinning -> authority stripping and origin rewrite in the transport -> restore-barrier check before startup -> bounded Beam gateway/connector admission and retry. The reusable mechanism is not a generic tunnel; it is the combination of canonical policy normalization, per-request address revalidation, and fail-closed recovery control.

What stands out is that the code refuses to trust stale authority: `Normalize` canonicalizes and hashes the CA bundle, `Checker.Check` validates every DNS answer before reporting readiness, `Transport.RoundTrip` re-resolves and rewrites only path/query onto the registered origin, and `restorebarrier.Check` refuses to start if restore state is ambiguous. The main gap is live reconnect and restore churn; source and tests are strong, but the operational path still needs proof under restart and DNS-change pressure.

See [tunnexio/tunnex](../repositories/tunnexio-tunnex.md).

### JosefHobler/stm32-ccsds-node

This repository informs `satellites-space-systems` through a watchdog-supervised CCSDS telemetry/telecommand loop. The verified flow is: UART RX interrupt -> stream-buffer ingestion -> framed packet length check and CRC/version validation -> command dispatch and telemetry emission -> watchdog refresh on alive bits -> UART output or hardware reset on fault. The companion C++ tests prove byte-identical encode/decode behavior across the wire format and reject corrupted, truncated, or invalid-version frames.

What stands out is the pairing of runtime liveness and packet recovery: the telecommand task slip-resyncs on bad framing, the telemetry task keeps a minimum heartbeat under the watchdog window, and the conformance tests assert byte-for-byte agreement across implementations. The main gap is runtime proof on actual hardware or an emulator under packet loss, corruption, and watchdog stalls.

See [JosefHobler/stm32-ccsds-node](../repositories/JosefHobler-stm32-ccsds-node.md).
