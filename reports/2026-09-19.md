## Detailed Reviews

### docling-project/docling

The reusable mechanism is the threaded PDF pipeline, not the full document-conversion surface. `DocumentConverter` selects `StandardPdfPipeline`, which preserves page numbering and partial-success output while `StandardPdfPipeline` handles timeouts, failed pages, and deferred image materialization. The main comparison point is a flat converter that drops failed pages or collapses everything into a single success/failure result.

The current head keeps the same architecture and the evidence remains strong: page retention, shutdown timeout, and pipeline-cache behavior are test-backed, while the current refactor is only a version bump. The main adoption gap is runtime validation on mixed-quality PDFs under real backend/model combinations.

See [docling-project/docling](../repositories/docling-project-docling.md).

### DefGuard/gateway

This repository contributes a reconnect-safe private-network gateway mechanism. `GatewayServer` handles the mTLS control plane, `Gateway` reconciles interface and firewall state, and `purge` plus the disconnect grace period turn a dropped control-plane connection into a recoverable state transition rather than a terminal failure.

The useful comparison is a gateway daemon that blindly restarts the whole tunnel or keeps stale state alive. DefGuard diffs state instead, recreates missing interfaces, and applies only the necessary firewall mutations. The remaining gap is live reconnect validation under network churn.

See [DefGuard/gateway](../repositories/defguard-gateway.md).

### PX4/PX4-Autopilot

PX4 gives a reusable safety model for autonomy transitions: commander, health checks, and mission state determine whether a command is accepted, denied, or temporarily rejected. The strongest evidence is the combination of commander code, mission/failsafe logic, and simulator-oriented tests that cover sensor loss and mission recovery.

The baseline is a vehicle stack that accepts commands opportunistically and relies on manual operator intervention. PX4 instead hardens the ACK path around safety state. The open gap is a full SITL run for the exact command-loss and sensor-loss recovery path reviewed here.

See [PX4/PX4-Autopilot](../repositories/PX4-PX4-Autopilot.md).

### nasa/fprime

F Prime provides a context-preserving packet router, a command dispatcher with explicit response accounting, and a CFDP manager for delayed-connectivity file transfer. The useful mechanism is not the framework branding; it is the way buffer/context association is preserved across routing and out-of-order returns.

Compared with a stateless packet router, F Prime keeps a visible ownership table and protocol-specific handlers. The code and tests cover routing, dispatch, unknown packet handling, table-full degradation, and CFDP command cases. The remaining evidence gap is operational validation under realistic queue depth and packet ordering.

See [nasa/fprime](../repositories/nasa-fprime.md).
