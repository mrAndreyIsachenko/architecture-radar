## Detailed Reviews

- [juanfont/headscale](../repositories/juanfont-headscale.md) pins a private-network reconciliation loop where `MapRequest` arrives before `Connect`, policy reload rebuilds peer maps, approved routes persist across restart, and stale unhealthy bits are cleared when approvals disappear. Reusable as an ordered reconnect/policy route loop; not reusable as a generic VPN UI. The remaining blocker is live reconnect-recovery validation.
- [nasa/fprime](../repositories/nasa-fprime.md) pins a bounded uplink router that copies command packets immediately, hands file and unknown packets off without copying, and restores the original frame context on return. Reusable as a bounded context-preserving packet router; not reusable as a pointer trick without the same buffer-identity contract. The remaining blocker is runtime validation under a full uplink stack.
- [ArduPilot/ardupilot](../repositories/ArduPilot-ardupilot.md) pins a watchdog-driven failsafe ladder where stall detection reduces output, RTL runs through explicit stages, terrain failure restarts RTL conservatively, and SITL tests inject RC/GPS loss. Reusable as a mission failsafe state machine; not reusable as a flight-policy drop-in without sensor and mission assumptions. The remaining blocker is longer SITL churn and HIL-style confirmation.
