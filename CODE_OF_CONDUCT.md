# Code Of Conduct

This project is for evidence-backed research automation. Disagreement is expected; personal attacks are not.

## Expected Behavior

- Be direct, specific, and respectful.
- Critique claims, evidence, and implementations rather than people.
- Distinguish verified facts from interpretation.
- Assume public issues and pull requests may be read by people outside the immediate discussion.
- Help keep the project useful to maintainers and users who want to run or adapt the radar.

## Unacceptable Behavior

- Harassment, threats, insults, or sustained personal attacks.
- Discriminatory language or behavior.
- Publishing private information without permission.
- Deliberately misleading reports, fabricated evidence, or knowingly false claims.
- Using issues or pull requests for spam, promotion, or unrelated disputes.

## Enforcement

Maintainers may edit or remove comments, close issues, block accounts, or restrict participation when behavior harms the project.

Report conduct concerns privately to the repository owner through GitHub. For security vulnerabilities, use `SECURITY.md` instead.
